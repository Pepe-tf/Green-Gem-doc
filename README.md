# Green Gem
---
Green Gem is a Minecraft server inspired by the challenging and atmospheric worlds of Elden Ring and the Souls games. It features a story-driven adventure with tough enemies, strategic gameplay, and a world that reacts to player actions. Built over the years 2020 to 2025, this server offers a rich experience for players who enjoy high difficulty and immersive narratives.

## Features
---
- **Elden Ring / Souls Games-Inspired Gameplay**: Enjoy challenging combat, unforgiving enemies, and rewarding exploration.
- **Story-Driven Adventure**: Immerse yourself in a deep narrative with rich lore and hidden secrets.
- **Dynamic World**: The world evolves based on player actions and choices.
- **Custom Enemies & Bosses**: Face tough and unique enemies designed for high difficulty.
- **Questline & Events**: Complete quests and participate in world events to uncover the story.
- **Minecraft Java Edition Server**: Built on Minecraft Java Edition, with custom mechanics, gameplay, and features tailored to the Green Gem world.
- **AI Integration**: Features AI-driven interactions using Ollama, creating an engaging and reactive experience.

## Installation
---
To join the Green Gem server, follow these steps:

1. **Download Minecraft Java Edition**: Make sure you have the latest version of Minecraft Java Edition installed.
2. **Join the Green Gem Server**:

   - Server IP: `mc.ggem.buzz`
   - Port: `25565`
   
3. **Connect and Play**: Log into the server and start your journey into the world of Green Gem!

## Gameplay
---
1. **Challenging Combat**: Combat is tough and requires strategy. Be prepared to face formidable enemies and bosses.
2. **Exploration**: Explore a vast world filled with hidden secrets, treasure, and lore.
3. **Progression**: Unlock new abilities, gear, and weapons to improve your chances in battle.
4. **Multiplayer**: Team up with other players to tackle difficult challenges or venture solo for an even more intense experience.
